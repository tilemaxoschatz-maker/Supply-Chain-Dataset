# Supply Chain Performance Analysis

Project Overview

This project presents an end-to-end supply chain analysis using Python. The objective is to evaluate operational efficiency by examining inventory management, supplier performance, logistics operations, manufacturing efficiency, transportation methods, and financial performance.

The project follows a complete analytical workflow including data cleaning, feature engineering, exploratory data analysis, business-oriented visualizations, and actionable recommendations.

Business Objective

The primary objective is to identify operational inefficiencies and provide data-driven recommendations that improve inventory management, supplier selection, manufacturing performance, logistics operations, and overall supply chain profitability.

Key Findings
Product profitability differs significantly across categories.
Inventory turnover highlights opportunities for stock optimization.
Supplier performance varies considerably in quality and lead times.
Transportation decisions involve cost–quality trade-offs.
Manufacturing costs are influenced by factors beyond production volume.
Logistics optimization can improve both operational efficiency and profitability.
